# NAD — сайты с характером

Персональный сайт-портфолио: концепция, структура, дизайн и сборка страниц с атмосферой.

## О проекте

Одностраничный сайт на HTML, CSS и JavaScript. Тёмная editorial-тема, акцент на типографику, градиенты и мягкие анимации.

### Блоки

1. **Hero** — портрет, typing-анимация заголовка  
2. **Как я работаю** — процесс в 3 шага  
3. **Избранные проекты** — 4 кейса  
4. **Подход** — почему смотрю на проект целиком  
5. **Инструменты** — стек  
6. **Аудитория** — кому подойдёт работа  
7. **Манифест** + **Отзывы** + **CTA**  
8. **Контакты** — Telegram и email  

## Структура

```
portfolio-nad/
├── index.html            # главная страница (нужна в корне для GitHub Pages)
├── css/
│   └── style.css
├── js/
│   ├── text-type.js      # анимация печати заголовка
│   ├── reveal.js         # появление блоков при скролле
│   └── testimonials.js   # переключение отзывов
├── images/
└── pulse/                # кейс: лендинг Pulse (также отдельно: pulse-landing)
    ├── index.html
    ├── css/
    │   ├── style.css
    │   └── mobile.css
    ├── js/main.js
    └── images/
```
